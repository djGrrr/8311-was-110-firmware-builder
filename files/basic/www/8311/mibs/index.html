8311 SNMP MIB files

The SNMP daemon on this device (enabled with the 8311_snmp fwenv) only exposes standard OIDs. These are the MIB definitions needed to resolve everything it serves, for use with snmpwalk -m or for import into an NMS. Most SNMP tools already ship all of these.

  • ENTITY-MIB — physical inventory (entPhysicalTable): module vendor, model, hardware revision, serial number
  • ENTITY-SENSOR-MIB (RFC 3433) — hardware sensors (entPhySensorTable): transceiver and CPU temperatures, supply voltage, TX bias current, TX/RX optical power
  • NET-SNMP-EXTEND-MIB — PON specific values (nsExtendOutput1Line): ploam-state, rx-power-dbm, tx-power-dbm, active-bank, pon-mode, module-type, fw-version
  • NET-SNMP-MIB — base definitions required by NET-SNMP-EXTEND-MIB

Standard MIB-II subtrees (system, interfaces/IF-MIB, ip, etc.) are served natively by the agent. Example:

snmpwalk -v2c -c public <device-ip> entPhySensorValue
snmpwalk -v2c -c public <device-ip> 'NET-SNMP-EXTEND-MIB::nsExtendOutput1Line'
